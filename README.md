# Hickory Accounting

**Personal Financial Management for Linux**

Hickory Accounting is a terminal-based accounting program designed to provide simple, straightforward personal financial management on Linux.

### Features
- Income and expense tracking
- Account management
- Repeating transactions
- Transaction splits and transfers
- SQLite database storage
- Reports and backups

### Installation

Download Hickory from the official website:

https://www.hickoryaccounting.com/

See the included README for installation instructions.
